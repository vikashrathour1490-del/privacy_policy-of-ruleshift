# Rule Shift privacy policy

This repository contains a publishable static privacy policy page for Rule Shift.

## Deploy

`index.html` is fully self-contained and can be deployed to any static host (for example: GitHub Pages, Netlify, Cloudflare Pages, or S3 static website hosting).

### Quick publish options

1. **GitHub Pages**
   - Push this repository to GitHub.
   - In **Settings > Pages**, select deployment from the default branch root.
   - Open the generated Pages URL.

2. **Any static web host**
   - Upload `index.html` as the site root document.
   - Ensure the host serves `text/html` for `.html` files.
